# 3mixer – ladda ner

3mixer är en gratis ljudmixer för Windows. Den har tre kanaler, **Spel**, **Chatt** och **Media**, och varje kanal
har egen volym, en egen utgång (till exempel hörlurar eller högtalare) och en egen ljudprofil. Du väljer själv vilken
app som hör till vilken kanal.

## Installera

1. Öppna [senaste versionen](../../releases/latest) och ladda ner **3mixer-Setup.exe**.
2. Dubbelklicka på filen och tryck **Installera**. Ingen administratör behövs, och 3mixer installeras bara för dig.
3. Windows kan visa **"Windows skyddade datorn"**, eftersom programmet är nytt och inte köpt-signerat.
   Tryck **Mer info** och sedan **Kör ändå**.
4. 3mixer hamnar i Start-menyn.

Kräver Windows 10 (21H2) eller Windows 11, 64-bitars. Du behöver inte installera .NET, det följer med.

## Bra att veta

- 3mixer ändrar inget ljud förrän du slår på **Styr ljudet**.
- **Släpp alla appar** ger apparna full volym och Windows egen utgång igen.
- **Uppdatera:** tryck på i-knappen och sedan **Sök efter uppdatering**. Finns det en ny version står det
  **Ny version finns** överst i fönstret.
- **Avinstallera:** Inställningar → Appar → Installerade appar → 3mixer.

Här finns bara installationsfilen och den signerade versionsfilen (`latest.json`), som 3mixer kontrollerar innan den
uppdaterar sig. Ingen källkod.
